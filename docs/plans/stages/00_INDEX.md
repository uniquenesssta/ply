# R2–R14 快速框架实施版索引

## 这版与上一预览版的区别

- 阶段级内容继续详细：目标、结构、主链、状态归属、阶段里程碑、修复清单、完成条件都保留。
- 普通 Atomic Task 大幅简化，只保留：目的、模块、主链、实施重点、基本验证、完成判断。
- 只有高风险任务额外增加“高风险约束”。
- 明确采用“骨架优先、主链优先、边跑边修、R12 集中硬化”的开发节奏。
- 不要求每个小任务覆盖全部边缘场景后才能继续。
- 仍然保持职责模块化，不能以“快速”为理由把所有东西堆回单文件。

## 推荐执行方式

当前已经在 R1。后续直接以对应阶段文档为执行基线。每个 Atomic Task 开始时再结合当时真实代码做影响分析，而不是机械照任务书创建所有规划文件。

若某个普通任务主链已经工作但还有非阻断边缘问题，可记录在该阶段“框架打通后优先修复”中继续推进；涉及 crash、deadlock、UAF、数据损坏、错误状态所有权或无法 build 的问题必须立即处理。
