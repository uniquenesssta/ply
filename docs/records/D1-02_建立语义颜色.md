## 5. 实施中发现并修复的问题

### 5.1 Semantic Paint 绑定导致透明度被重置

首次把框架颜色接入 Semantic Variable 后，视觉回归截图发现视频区域近乎纯白。

定位结果：

- `setBoundVariableForPaint` 后原 Paint opacity 被重置为 `1.0`；
- `Soft Vignette` 从原 `3%` 变成 `100%`，直接覆盖全部氛围光；
- Glass、Timeline、Selection 等透明度也同时被放大。

已修复：

- 保留 Semantic Variable binding；
- 按绑定前真实取样恢复 42 个 Fill opacity 与 8 个 Stroke opacity；
- Main / Fullscreen / Playlist Inspector 再次截图后，紫、青、暖光和玻璃层恢复正常。

### 5.2 Semantic 文档板两次布局问题

第一次截图发现右下 Inspector 组与规则说明发生覆盖。

第一次修正又因 Node ID 引用错误：

- 错把 `inspector/search` 的 `Semantic Swatch` 节点 `14:162` 移到 `y=1390`；
- 真正的 `Semantic Notes` 是 `14:165`。

已修复：

- `14:162` 恢复 `y=12`；
- `14:165` 下移到 `y=1390`；
- Board 高度扩展为 `1530`；
- 最终截图复核无裁切、无覆盖。
